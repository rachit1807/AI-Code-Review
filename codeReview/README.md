# 🤖 AI Code Review Platform

An AI-powered code review platform that analyzes source code and provides suggestions for readability, performance, security, maintainability, and best practices.

## 🚀 Features

- AI-powered code analysis
- Syntax highlighting
- Multiple programming language support
- Code quality scoring
- PDF report generation
- Dark/Light theme
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- PrismJS
- Axios

### Backend
- Node.js
- Express.js
- Google Gemini API

## 📂 Project Structure

```
AI-Code-Review/
├── frontend/
└── backend/
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/rachit1807/AI-Code-Review.git
cd AI-Code-Review
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🌐 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
GEMINI_API_KEY=YOUR_API_KEY
```
